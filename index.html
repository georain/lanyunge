服务器文档

玩家手册 · 服务器规则 · 玩法指南

一方净土，静候君临。

写在前面

欢迎来到澜云阁——一个安静、纯粹、不问来处的Minecraft公益服务器。

澜云阁的诞生，源于一个简单的念想：在这个喧嚣的时代，为热爱《我的世界》的旅人保留一片可以慢下来、静心搭建与探索的天地。这里不追求人数众多，不追逐版本前沿，只愿为每一位偶然到访的玩家，提供一段舒心、自在的方块时光。

本手册将带你了解澜云阁的一切。内容略长，但关乎你在这里的旅途，愿君耐心一阅。

服务器的定位与理念

我们是公益服

澜云阁承诺不以任何形式盈利。服务器运营所需的一切成本由服主个人承担，不接受任何形式的捐赠或赞助。这里没有VIP、没有特权、没有"氪金变强"——每一位玩家都是平等的。

我们是"人很少"的服务器

坦诚地说，澜云阁目前基本处于0人在线的状态。但这并非缺陷，而是特色。

这意味着：

  • 资源丰富：世界广阔，未开发的处女地比比皆是
  • 延迟极低：没有服务器负载压力，红石、生电也能流畅运行
  • 真正的自由：不需要排队、不需要抢资源点、不用担心被人打扰
  • 独享的宁静：你可以把这里当作自己的单人世界，偶尔有人上线打个招呼，便是一份意外的惊喜

如果你厌倦了大型服务器的嘈杂和拥挤，澜云阁的"空旷"恰是难得的礼物。

我们鼓励长期留存

尽管目前人少，但每一位认真建筑的玩家，都能在这里找到归属感。服务器定期备份存档，不会轻易重置，你的每一个作品都会被妥善保存。

连接指南

准备工作

  1. 游戏版本：请确保使用 Minecraft Java Edition 1.20.1。其他版本将无法进入服务器。
  2. 无需正版：服务器关闭了正版验证（online-mode=false），无论你是否拥有正版账号，均可直接进入。

如何进入服务器

  1. 打开游戏启动器，启动 Minecraft 1.20.1 客户端
  2. 点击「多人游戏」→「添加服务器」
  3. 在「服务器地址」栏输入：mc.georainl.cc.cd
  4. 点击「完成」，双击服务器名称即可进入

lightbulb 提示：由于没有正版验证，你可以使用任意游戏昵称登录。但请注意，你的昵称就相当于你的身份标识——建议固定使用同一个名字，以免丢失建筑和进度。

服务器规则

澜云阁奉行"最小干预、最大自由"的管理理念。规则不多，但请务必遵守。

一、禁止作弊与非法Mod

严禁使用任何作弊客户端、矿物透视、飞行外挂、自动连点等破坏公平性的第三方工具。服务器虽无严格的反作弊系统，但管理员会定期巡查，违规者将面临永久封禁，不予解封。

合理的辅助Mod（如小地图、光影、性能优化等）不在此列。

二、尊重他人的劳动成果

未经他人允许，不得破坏、修改或占用其他玩家的建筑、设施和物品。这是Minecraft世界最基本的底线。

如果发现遗迹、废弃村庄等自然生成建筑，欢迎探索，但请勿过度破坏其原有风貌。

三、禁止恶意利用游戏漏洞

任何利用Bug进行刷物品、复制、卡服等行为，都将被视为严重违规。

四、和谐交流，友善待人

服务器内聊天请保持基本礼貌。禁止发布色情、政治敏感、人身攻击、恶意引战等内容。和谐的社区需要每一位玩家的共同维护。

五、关于大规模生电设施

澜云阁的服务器配置相对有限（2核5G存储），大规模、高负荷的农牧场、刷怪塔、红石机械请适度建造。如果服务器因此出现严重卡顿，管理员可能会要求拆除或优化。

生存指南

初始出生点

初次进入服务器，你将在世界出生点醒来。出生点周围有一片安全区域，建议在此附近建立你的第一个据点。

资源世界

服务器当前使用的为默认世界生成，包含主世界、下界（地狱）和末地。所有维度均对外开放，资源丰富。

lightbulb 温馨提示：由于人少，资源几乎等于无限。但请珍惜每一棵树、每一片土地——这是大家的共同家园。

建筑与领地

目前服务器未安装领地保护插件（如WorldGuard）。这意味：

  • 你可以自由选择任何地点建造
  • 建筑不受系统保护，但受到规则保护（禁止破坏他人建筑）
  • 如果你担心自己的作品被意外破坏，建议在建筑旁留下告示牌，注明所有者

未来根据玩家需求，可能会酌情引入轻量级的领地保护机制。

死亡掉落

服务器当前采用默认死亡机制——死亡后物品会掉落，经验值会损失。请妥善保管你的贵重物品。

关于"闪电存储"（2G闪存）

服务器存储空间为2G闪存（即高速存储），虽然读写速度快，但总容量有限。这意味着：

  • 世界文件大小会持续增长
  • 当存储接近上限时，管理员可能需要清理未加载的边缘区块或长期不活跃玩家的数据
  • 建议不要生成超大范围的地图（如跑图数万格），以减少世界文件体积

服务器管理与技术支持

管理员

澜云阁目前由服主个人维护。管理员在线时间不固定，但会定期检查服务器状态和备份存档。

如果遇到紧急问题（如无法登录、严重卡顿），可尝试在服务器内留言或通过其他渠道联系管理员。

数据备份

服务器存档定期自动备份至云端。即使发生意外崩溃或数据损坏，也能将世界恢复到最近一次备份的状态。你的建筑和心血，我们和你一样重视。

插件与功能

目前服务器保持接近原版体验，未安装大型玩法插件。未来可能根据实际需求，添加一些轻量级辅助插件（如基础指令、经济系统等），但不会改变原版生存的核心玩法。

写给每一位玩家的话

澜云阁还很小，人很少，像一座坐落在云海深处的阁楼，等待有缘人的到来。

也许你只是一个偶然路过、想安安静静挖几天矿的旅人；也许你打算在这里建一座大城、留下一段回忆——无论哪种身份，这里都欢迎你。

人少，意味着没有KPI、没有卷、没有攀比。你可以把这里当作自己的私人世界，慢慢玩，慢慢建，偶尔有人上线，互相打个招呼，看看彼此最近盖了什么新房子——这大概就是澜云阁存在的全部意义。

服务器重启不会清档，管理员不轻易干涉玩家，一切规则以"尊重与友善"为底线。
